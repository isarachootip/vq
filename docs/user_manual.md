# คู่มือการใช้งานระบบบริหารจัดการคิวติดตั้งงาน (vService Operations Manual)
*คู่มืออธิบายการทำงานของระบบจำลอง vService ทั้งส่วนหน้าร้านลูกค้า และแผงควบคุมหลังบ้าน*

---

## 1. ภาพรวมระบบ (System Overview)

ระบบ **vService** ได้รับการออกแบบขึ้นมาเพื่อบริหารจัดการการรับงานติดตั้งอย่างครบวงจร ประกอบไปด้วย 2 ส่วนหลัก:
1. **หน้าร้านลูกค้า (Storefront Portal)**: ลูกค้าเข้าชมรายการบริการ ค้นหาช่างเทคนิคที่เหมาะสมผ่านระบบจัดคู่อัจฉริยะ (Match Score) และลงชื่อสมัครเป็นช่างร่วมงาน
2. **แผงควบคุมหลังบ้าน (Admin Dispatch Console)**: แผงจัดการคิวตารางงานประจำวัน, คัดกรองใบสมัครช่างติดตั้ง, บริหารแคตตาล็อกสินค้า, จัดการแบนเนอร์ประชาสัมพันธ์ และตั้งค่าน้ำหนักคะแนนประมวลผลจับคู่ช่าง

---

## 2. การทำงานฝั่งหน้าร้าน (Storefront Portal)

### 2.1 สไลด์แบนเนอร์โฆษณา (Marketing Banner Slider)
* **การแสดงผล**: แบนเนอร์ขนาดใหญ่แสดงผลภาพกราฟิกคมชัด สว่างใส ที่หน้าหลักของพอร์ทัล
* **การหมุนสไลด์อัตโนมัติ (Auto-Slide)**: แบนเนอร์จะสไลด์เปลี่ยนรูปเองโดยอัตโนมัติตามระยะเวลา (วินาที) ที่ตั้งค่าไว้จากแผงหลังบ้าน

### 2.2 การจองบริการติดตั้งของลูกค้า (Service Booking Flow)
1. **เลือกบริการ**: ค้นหาหรือแยกประเภทบริการติดตั้ง (เช่น ล้างเครื่องปรับอากาศ, ปูพื้นไม้ SPC, ติดตั้งครัวบิลต์อิน) 
2. **ระบบคำนวณจับคู่ช่างอัจฉริยะ (Smart Match Score %)**: 
   * เมื่อคลิกเลือกบริการและระบุพื้นที่บริการ (โซนพิกัด) ระบบหลังบ้านจะคำนวณหาช่างที่เหมาะสมที่สุดมาเสนอให้ลูกค้าเลือกทันที โดยคะแนนความเข้ากันได้ (%) คำนวณจาก:
     * ความตรงกันของพื้นที่ปฏิบัติงาน (Primary/Secondary Zone)
     * ระดับทักษะเลเวลที่ช่างถือกรรมสิทธิ์ (Skill Level Match)
     * อันดับระดับความพรีเมียม (Gold / Silver Tier)
     * คะแนนเฉลี่ยรีวิวของลูกค้าที่เคยมาใช้บริการ
     * แต้มหักคะแนนความผิดทางกฎระเบียบ (E-CN Penalty Multipliers)
3. **เลือกวันและระบุเวลานัดหมาย**: ลูกค้าสามารถเลือกเวลาติดตั้งที่สะดวกเพื่อยืนยันคิวจองงานและส่งงานเข้าสู่แผงหลังบ้านทันที

### 2.3 การสมัครเข้าเป็นช่างติดตั้ง (Technician Onboarding Form)
* ช่างรายใหม่สามารถสมัครร่วมงานได้โดยตรงผ่านหน้าร้านหลัก โดยกรอกข้อมูล: ชื่อ-นามสกุล, เบอร์โทรศัพท์, **LINE ID**, พื้นที่โซนที่ต้องการรับงาน, เลือกทักษะสกิลงาน, ระบุประสบการณ์พร้อม **อัปโหลดภาพโปรไฟล์** ของตนเอง
* เมื่อลงทะเบียนสำเร็จ ข้อมูลจะถูกจัดเข้าสู่ระบบจัดการใบสมัครงานช่างเทคนิคฝั่งหลังบ้านทันที

---

## 3. การทำงานฝั่งหลังบ้าน (Admin Dispatch Console)

### 3.1 ตารางปฏิทินงานติดตั้งและระบบฟิลเตอร์ค้นหา (Calendar Scheduler Dashboard)
แผงหน้าหลักเปลี่ยนจากรายการทั่วไปเป็น **ตารางปฏิทินการทำงานแบบรายวัน**:
1. **การแสดงผลปฏิทิน**: ในแต่ละช่องวันในปฏิทินจะแสดงไอคอนนับจำนวนคิวงานแยกตามสถานะ (เช่น งานรอจับคู่ช่าง, งานรอเข้าติดตั้ง, งานเสร็จสมบูรณ์)
2. **การคัดกรองงานแบบละเอียด (Concurrent Filters)**:
   * **กรองตามวัน (Date Filter)**: คลิกเลือกวันที่ต้องการในปฏิทินเพื่อแสดงเฉพาะรายการงานในวันนั้นๆ
   * **ช่องค้นหาข้อความ (Search)**: ค้นหาคำสำคัญ เช่น ชื่อลูกค้า, เบอร์โทรศัพท์ หรือเลขที่ใบสั่งจอง
   * **กรองตามโซนพื้นที่ (Zone)**: เลือกคัดกรองงานเฉพาะเขตพื้นที่ปฏิบัติงาน
   * **กรองตามสถานะงาน (Status)**: กรองงานแยกตามสถานะเพื่อการติดตามงานได้สะดวก

### 3.2 บันทึกคิวจองงานด้วยมือผ่านแอดมิน (Manual Booking)
ในกรณีลูกค้าส่งรายละเอียดทางโทรศัพท์หรือ Line OA แอดมินสามารถเปิดฟังก์ชัน **"บันทึกคิวจอง (Line / โทรศัพท์)"** เพื่อบันทึกงานเอง:
* ป้อนข้อมูลลูกค้า: ชื่อ, เบอร์ติดต่อ, บริการที่จอง, โซนพื้นที่จัดส่งช่าง, วันนัดหมาย, ช่วงเวลา และ **แหล่งที่มาการติดต่อ (Source)**
  * แหล่งที่มาสนับสนุน: `Line OA`, `Call Center 1308` และ `Walk-in`
* เมื่อบันทึกสำเร็จ คิวงานจะเข้าไปปรากฏในปฏิทินจัดส่งช่างในสถานะ `Pending Dispatch (รอจับคู่ช่าง)` และคำนวณพิกัดช่างให้อัตโนมัติ

### 3.3 แผงคัดเลือกช่างติดตั้งร่วมงาน (Technician Recruitment Kanban Board)
หน้าจัดการผู้สมัครช่างใช้บอร์ดคัดเลือกแบบลากย้ายขั้นตอน (Recruitment Stages):
* **ขั้นตอนสถานะ**: มี 5 สถานะชัดเจนได้แก่ `Reject` (ปฏิเสธ), `Accept` (ยอมรับพิจารณา), `Approve` (ผ่านเกณฑ์ประเมิน), `Sign Contract` (เซ็นสัญญาร่วมงาน) และ `Employee` (เลื่อนขั้นเป็นช่างอย่างเป็นทางการ)
* **การเลื่อนสถานะช่างอัตโนมัติ (Auto-Promotion)**:
  * > [!IMPORTANT]
    > เมื่อแอดมินกดเลื่อนสถานะใบสมัครของช่างไปที่ขั้น **`Employee` (บรรจุงาน)** ช่างรายนั้นพร้อมทั้งประวัติ ทักษะงาน และรูปถ่ายจะได้รับสิทธิ์โปรโมตเป็นช่างทีมงานอย่างเป็นทางการในทำเนียบช่างหลักของระบบ และมีสิทธิ์รับคิวติดตั้งงานในทันที

### 3.4 ตัวจัดการแคตตาล็อกบริการติดตั้ง (Service Catalog Manager)
* หน้าจอบริการ CRUD แบบยืดหยุ่นสำหรับแก้ไขบริการติดตั้งที่หน้าร้าน
* **ตัวอัปโหลดภาพในตัว (Base64 File Uploader)**: แอดมินสามารถอัปโหลดภาพประกอบสินค้าบริการใหม่จากเครื่องคอมพิวเตอร์ หรือเลือกใช้คลังรูปภาพแนะนำหลักเพื่อนำไปเปลี่ยนภาพบริการหน้าร้านให้สวยสะดุดตาได้ทันที

### 3.5 ตัวจัดการแบนเนอร์ประชาสัมพันธ์ (Banner Manager)
* หน้าควบคุมแบนเนอร์โฆษณาหน้าร้าน
* สามารถระบุ ลิงก์ URL ภาพภายนอก หรือใช้ตัวเลือก **อัปโหลดภาพแบนเนอร์โฆษณาใหม่ตรงจากคอมพิวเตอร์** โดยตัวโปรแกรมรองรับการแสดงผลแบนเนอร์ขนาดยาวแบบคมชัดสูง (High Definition) พร้อมพิมพ์หัวข้อแคมเปญ แท็กโปรโมชันและคำบรรยายใต้ภาพ

## 4. การตั้งค่าระบบหลังบ้าน (Backend Configurations Settings)

เมนูนี้ช่วยควบคุมพฤติกรรมการคำนวณงานของระบบทั้งหมด:
1. **ค่าน้ำหนักคะแนนประมวลผล (Match Weights Parameters)**: ปรับสัดส่วนค่าน้ำหนักคะแนนการพิจารณาช่าง เช่น สัดส่วนทักษะของช่าง, ประสบการณ์, และพื้นที่รับงาน โดยมีเทมเพลตสำหรับใช้งานด่วน (เช่น เน้นคุณภาพช่างสูงสุด หรือ เน้นความรวดเร็วและสาขาใกล้เคียงช่าง)
2. **แต้มบทลงโทษช่างชั่วคราว (Penalty Thresholds)**:
   * **Cooldown Threshold**: เกณฑ์แต้มความผิดสะสมจาก E-CN สูงสุด หากช่างเทคนิคทำผิดกฎเกินเกณฑ์นี้ จะถูกจำกัดพักงาน 7 วัน
   * **Suspension Threshold**: เกณฑ์การระงับสิทธิ์ช่างถาวร
3. **ระยะเวลาสลับสไลด์แบนเนอร์ (Banner Slide Delay Slider)**: แถบเลื่อนวินาทีสำหรับควบคุมสปีดสไลด์หน้าร้านลูกค้า (2 ถึง 12 วินาที)
4. **Google Maps API Key (ฟังก์ชันสำหรับอนาคต)**: ช่องรับ API Key เพื่อเตรียมสลับระบบพิกัดและระบบคำนวณแนะนำที่อยู่ลูกค้าผ่านระบบ Google Cloud ในอนาคต

## 5. การจัดเก็บข้อมูลบนเครื่องเบราว์เซอร์ (Local Storage Data Security)

เพื่อป้องกันข้อมูลที่ป้อนเข้าระบบสูญหายจากการปิดเบราว์เซอร์หรือการ Redeploy ตัวแอปพลิเคชัน:
* ระบบ **vService** ได้รับการฝังเครื่องมือความปลอดภัยบันทึกข้อมูลแบบ **LocalStorage** ที่จะดึงข้อมูลประวัติการทำงานขึ้นแสดงผลในระดับ Local เสมอ
* ระบบมาพร้อมกับเครื่องมือตรวจสอบความสอดคล้องของประเภทตัวแปร (Type-Safe State Loader) ช่วยคัดกรองข้อมูลเสียในเครื่องของคุณเพื่อป้องกันอาการหน้าจอขาวค้าง (White Screen Crash) อย่างถาวร
